# Coffee
> It's libre!

Welcome to the development repository of Coffee, a completely libre, non-JVM implementation of Minecraft: Java Edition. This project currently does not target modern versions of Minecraft, due to the technical complexity. At the current moment, we are targeting **Beta 1.7.3.**

Specifically, singleplayer. Multiplayer is NOT in scope at this time.

> [!TIP]
> In this context, "targeting" means we're trying to be as functionally identical to the target version as possible. This comes in the form of playing the version, watching videos that feature the target version, so on. Decompiling Java .class files is explicitly disallowed.
